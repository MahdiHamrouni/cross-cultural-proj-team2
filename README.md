# 🌿 Careline — Mental Health Application

> A cross-cultural web application designed to support mental health awareness and well-being.

---

## 📖 About

**Careline** is a web-based mental health application developed as part of a cross-cultural collaborative project. The goal is to create an accessible, empathetic, and culturally inclusive platform that helps users find support, resources, and tools for their mental well-being.

This project was built by a diverse international team, bringing together different cultural perspectives to design a more inclusive and effective mental health experience.

## ⚙️ Getting Started

### Prerequisites

- A modern web browser
- (Optional) A local server for development (e.g. Live Server in VS Code)

### Run locally

```bash
# Clone the repository
git clone https://github.com/MahdiHamrouni/cross-cultural-proj-team2.git

# Navigate into the project
cd cross-cultural-proj-team2

# Open index.html in your browser or start a local server
```
